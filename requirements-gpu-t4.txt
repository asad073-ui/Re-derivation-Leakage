#
# The three T4 facts that decide this file:
#
#   1. NO flash-attn. FlashAttention-2 requires SM80+ (Ampere). T4 is SM75. The
#      upstream open-unlearning README installs `flash-attn==2.6.3`; that step MUST be
#      skipped here and the model config overridden to attn_implementation=sdpa.
#      Installing it either fails to build or fails at runtime.
#
#   2. NO bfloat16. Turing has no bf16 datapath. Any `torch_dtype: bfloat16` coming out
#      of an open-unlearning config must be overridden to float16 for eval. For
#      training it must go to float32 (see 3).
#
#   3. NO gradient-ascent-family TRAINING on this device. NPO/GA push the loss upward
#      without bound; fp16 GradScaler NaNs on that objective. It is silent corruption,
#      not a crash. src/rdl/hardware.py refuses to start training when
#      supports_bf16 is False unless --allow-fp16-training is passed. Train on the
#      RTX 3090 (Ampere) or the H100 instead.
#
