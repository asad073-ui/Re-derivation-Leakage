# THE PHASE-0 PRODUCTION FILE. `configs/env/vast_rtx3090.yaml` is the matching profile.
#
# Ampere+ gives us the two things the T4 cannot:
#   - bfloat16: gradient-ascent-family objectives (GA, NPO) are numerically sound in
#     bf16 and NaN in fp16. This is why training lives here and nowhere else.
#   - FlashAttention-2: SM80+ silicon. Safe to REQUEST — but only once the wheel is
#     actually installed. See the flash-attn block below.
#
# Note for the 3090 specifically: 24 GB single-GPU cannot reproduce upstream's 2x L40s
# DeepSpeed ZeRO-3 effective-batch-32 setup exactly. Upstream warns their numbers shift
# when the distributed setup changes. Any training run here is a NEW number, not a
# reproduction — record it as such in docs/04_decisions.md.

# flash-attn is DELIBERATELY NOT INSTALLED BY THIS FILE.
#
# It needs `--no-build-isolation` and a matching nvcc (a CUDA *devel* image, not the
# runtime one most cloud templates ship), and takes ~20 min to build. `pip install -r`
# would therefore fail on the majority of rented Ampere boxes, over an OPTIONAL
# dependency: without the wheel, hardware.py resolves attention to sdpa, records the
# choice in every report, and everything runs.
#
# To build it (option B in docs/07_rtx3090_runbook.md):
#   INSTALL_FLASH_ATTN=1 bash scripts/01_bootstrap_openunlearning.sh
# which is equivalent to:
#   pip install --no-build-isolation flash-attn==2.6.3
#
# Whichever you choose, choose ONCE: FA2 and SDPA numbers must not be mixed inside one
# comparison. See ADR-0031.
